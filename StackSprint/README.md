# StackSprint iOS

Unzip this folder and double-click **StackSprint.xcodeproj**. Choose an iPhone/iPad simulator and press Run. For backend setup, device signing, current limitations, and production requirements, read **SETUP.md** first.

Frontend: SwiftUI native lessons, quizzes, accounts, sharing, CSV export, plus the existing game studio in WKWebView.

Backend: Supabase Auth + PostgreSQL REST API, with deployable schema and per-user row-level policies in `backend/schema.sql`. Requires your hosted project and public client configuration. No secrets or hosted backend are included.

This is development source, not an App Store-ready binary. See **VERIFICATION.md** for checks performed.
